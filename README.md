# Склад

Облік компонентів для Windows і Android: одна програма (PWA), що встановлюється
як звичайний застосунок з іконкою, і спільна хмарна база — прихід, зроблений
на телефоні, одразу видно на ПК.


**Робоча адреса:** <https://crazysharkxo.github.io/sklad/>

## Що вміє

- **Замовлення**: прийом із описом продукту (що замовили, замовник, кількість,
  термін), чекліст «що потрібно зробити» з відмітками хто й коли виконав,
  деталі зі складу під замовлення (можна додати цілий комплект) — видно, чого
  бракує, а видача списується під це замовлення.
  Етапи: *Нове → В роботі → На тестуванні → Готово → Відвантажено*; тестування
  може **повернути на доопрацювання** (лише з коментарем, що не так).
  Замовлення передається між **відділами**; кожен користувач позначає свій відділ
  і бачить «що чекає на мій відділ» (число на вкладці). Уся історія передач і
  коментарів — у картці замовлення.
- **Номенклатура**: назва, фото, код/штрихкод, категорія, одиниця (шт, м, кг…),
  місце зберігання, мінімальний залишок, примітка. Архів замість видалення.
- **Прихід і видаток** документом на кілька позицій: пошук за назвою або кодом,
  сканування камерою чи USB-сканером, «постачальник / кому», коментар.
- **Залишки рахуються самі** — з журналу руху, а не вписуються руками. Тому вони
  завжди сходяться з історією. Видати більше, ніж є, програма не дасть
  (перевірка на сервері, навіть якщо двоє видають одночасно).
- **Журнал** усіх операцій: хто, коли, що, кому. Фільтр за типом і датами.
  Помилкову операцію можна **скасувати** — запис лишається в історії як скасований.
- **Мінімальний залишок**: позиції нижче мінімуму підсвічуються, окремий список
  «Дозамовити» (і в Excel).
- **Комплекти**: «Дрон = 4 мотори + 1 польотник + …». Видача комплекту списує
  всі компоненти одним рухом; видно, скільки виробів можна зібрати із залишків
  і чого бракує.
- **Інвентаризація**: вписуєте фактичну кількість, програма показує розбіжності
  й проводить коригування. Недороблений підрахунок не губиться при перезавантаженні.
- **QR-етикетки**: друк наліпок на полиці й коробки; скан етикетки відкриває позицію.
- **Excel**: експорт залишків і журналу; імпорт початкового списку з таблиці
  (є шаблон).
- Світла й темна тема, працює на телефоні й на великому екрані.

## 1. Спробувати одразу (демо, без хмари)

Поки `js/config.js` порожній, програма працює в **демо-режимі**: дані лише в
цьому браузері. Запустіть `start.bat` (потрібен Python) — відкриється
`http://localhost:8080`.

## 2. Спільна база (Supabase, безкоштовний тариф)

1. Зареєструйтесь на <https://supabase.com> → **New project**. Регіон —
   *Central EU (Frankfurt)*. Пароль бази збережіть, але програмі він не потрібен.
2. **SQL Editor → New query** → вставте весь вміст `supabase/schema.sql` → **Run**.
   Має бути «Success». (Скрипт безпечно запускати повторно.)
3. **Authentication → Sign In / Providers → Email**: вимкніть
   **Allow new users to sign up** — інакше будь-хто з посиланням зможе
   зареєструватися.
4. **Authentication → Users → Add user → Create new user**: створіть **себе**
   (email, пароль, галочка **Auto Confirm User**). Перший користувач стає
   адміністратором; решту людей додавайте вже в програмі: **Ще → Користувачі та ролі**.
5. **Project Settings → API**: скопіюйте **Project URL** і **anon public** key
   у `js/config.js`:
   ```js
   export const SUPABASE_URL = 'https://xxxx.supabase.co';
   export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
   ```
   Ці значення не секретні — дані захищає вхід і правила в базі.
6. Кожен працівник: **Ще → Відділи → «Мій відділ»**. Стартові відділи —
   «Прийом замовлень», «Виробництво», «Тестування»; їх можна перейменувати й
   додавати свої.

> **Оновлення програми з новими таблицями.** Якщо база вже створена раніше,
> після оновлення файлів ще раз виконайте весь `supabase/schema.sql` у SQL Editor.
> Скрипт нічого не видаляє і не чіпає наявні дані — лише додає нове.

> Безкоштовний проєкт Supabase **призупиняється після 7 днів без жодного
> запиту**. При щоденній роботі цього не станеться; якщо сталося — у панелі
> Supabase натисніть *Restore project*, дані не губляться.

## 3. Розмістити в інтернеті (потрібно для телефону)

Камера і встановлення застосунку працюють лише через **https**. Найпростіше:

- **Netlify Drop**: відкрийте <https://app.netlify.com/drop> і перетягніть туди
  всю папку `Sklad` — отримаєте адресу `https://….netlify.app`.
- або **GitHub Pages**: репозиторій з цими файлами → *Settings → Pages →
  Deploy from a branch → main / root*.

Після зміни файлів просто завантажте їх знову — програма оновиться сама при
наступному відкритті з інтернетом.

## 4. Встановити як програму

- **Android** (Chrome): відкрийте адресу → меню **⋮** → **Встановити застосунок**
  (або «Додати на головний екран»).
- **Windows** (Edge або Chrome): відкрийте адресу → значок **Встановити** праворуч
  в адресному рядку. Програма зʼявиться в меню «Пуск» і відкриватиметься окремим
  вікном.

USB-сканер штрихкодів на ПК працює без налаштувань: він «друкує» код у поле
пошуку, і позиція відкривається.

## Користувачі та права

**Ще → Користувачі та ролі** (лише адміністратор):

- **Додати** — email, пароль для першого входу (генерується), роль, відділ.
- **Ролі** — готові набори прав: Адміністратор, Комірник, Виробництво, Лише перегляд;
  можна змінити або створити свої.
- **Свої галочки** — конкретній людині замість ролі: по кожному розділу (склад,
  прихід/видаток, комплекти, замовлення) окремо перегляд, зміна, видалення.
- **Замовлення всіх відділів** — без цієї галочки людина бачить лише замовлення свого відділу.
- **Заблокувати** — людина не зможе увійти; історія лишається. **Видалити** — те саме, але назавжди.

Права перевіряє сервер (Supabase), а не лише кнопки: без права видалення видалити не вийде
навіть в обхід програми. Хоча б один активний адміністратор лишається завжди.

## Резервні копії

Регулярно робіть **Ще → Залишки в Excel** і **Журнал в Excel**. На безкоштовному
тарифі Supabase автоматичних копій, які можна завантажити, немає.

## Для розробника

- Без збірки: чистий HTML/CSS/JS-модулі, бібліотеки лежать у `vendor/`.
- `supabase/schema.sql` — таблиці, представлення `stock` (залишок = сума руху без
  скасованих операцій), функції `post_operation` / `cancel_operation` з блокуванням
  рядків, правила доступу (RLS), сховище фото, realtime. Замовлення: статус і відділ
  змінює лише `move_order` (пише `order_events`); напряму їх не переписати — на
  таблиці `orders` дано лише колонкові права.
- Тести (потрібно `pip install pgserver playwright`, браузер — системний Edge):
  - `python tests/run_schema_test.py` — схема на справжньому Postgres 16;
  - `python tests/e2e_demo.py` — повний робочий цикл у браузері (демо-режим);
  - `python tests/e2e_supabase_mock.py` — вхід і виклики Supabase з підміненим API.
- Після зміни списку файлів оновіть `SHELL` і номер `CACHE` у `sw.js`.
